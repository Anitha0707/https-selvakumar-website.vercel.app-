SELVAKUMAR INSURANCE WEBSITE

PAGES (all share the same header and footer, in this order):
Home, About, Services, Awards, Commitment, Testimonials, Office, Our Logo, Contact.

PLAN PAGES
- Services links to every plan. Category pages: plans-life, plans-savings, plans-child, plans-retirement, plans-health.
- Each plan has its own page: plan-*.html (7 LIC plans, 8 Galaxy plans).

OTHER FILES
- assets/style.css, assets/site.js: shared styles and behaviour.
- assets/img/commitment-poster.jpg: poster shown on the Commitment page.
- favicon files sit in the site root and are linked from every page.

HOW TO RUN
Open the site folder in VS Code and run index.html with Live Server, or upload the folder contents to a static host. Keep index.html and assets/ together.

DISCLAIMER
Plan details are summaries. Check the latest official brochure and benefit illustration before purchase.
